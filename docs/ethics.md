# Ethics and bias

Owner: Member 5 (with input from all, especially Members 2 and 4).

- **Popularity bias:** do we keep pushing the same items? (Gini, coverage)
- **Fairness across age bands:** is quality similar for all ages?
- **Filter bubbles:** are lists too narrow? (diversity, novelty)
- **Privacy:** what customer data we use and why.
- **Sustainability:** does pushing more purchases conflict with the brand's sustainability goals?
